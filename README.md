# Pesquisa de Satisfação - TudoWeb

## Sobre o projeto

Este projeto foi desenvolvido em Python para realizar uma pesquisa de satisfação com clientes da empresa de marketing TudoWeb.

O programa coleta o nome, a idade e a opinião dos entrevistados sobre o atendimento prestado.

## Opções de atendimento

1. EXCELENTE
2. BOM
3. RUIM

## Funcionamento

O programa utiliza uma estrutura de repetição para realizar a pesquisa com 50 entrevistados e estruturas de decisão para identificar a opinião de cada participante.

Ao final, são exibidas as quantidades de respostas:

- EXCELENTE
- RUIM

## Teste

Foi realizado um teste com 10 entrevistados para validar o funcionamento do programa.
